# TeaQL .NET 0.3.0

Tracking: [release issue 43](https://github.com/teaql/teaql-dotnet/issues/43).

This release publishes the merged request intent and Trace Chain implementation,
including independent mutation graphs, loaded snapshots, relation aggregates,
facet tracing and safe SQL diagnostics. Generated examples exercise Checker
overlap, shared references, graph saves, stream capture and repeat bootstrap.

Regenerate applications when upgrading from 0.2.x: request and lineage
contracts have changed. Logging remains enabled by default, with sensitive
parameters masked and the existing disable controls preserved.

Release gates cover every source test project, every retained example,
an isolated generated consumer of immutable internal 0.3.0 packages, and public
NuGet delivery of all eleven packages. Optional external services remain
separate verification boundaries.
