# .NET 0.3.1

Tracking: [.NET #50](https://github.com/teaql/teaql-dotnet/issues/50) and
[conformance #109](https://github.com/teaql/teaql-conformance/issues/109).

The optional `TeaQL.Telemetry.OpenTelemetry` NuGet package is discovered at
context startup. Trusted environment variables enable full safe traces, metrics
and logs; disabled startup explains activation without creating SDK exporters.
Expanded SQL remains masked and correlates with the exact physical execution.

Owned SDK providers, bounded queues, finite flush/shutdown and explicit receiver
acknowledgement units preserve customer globals, business results and independent
mutation audit. The public package list includes the new optional module.

Regenerate libraries to adopt request-tree/search metadata and retire the separate
page terminal. Source/internal evidence is retained in the conformance
`2026-10-13-standard-telemetry-onboarding` report; final-package, signed-tag and
public-consumer verification are separate gates.
